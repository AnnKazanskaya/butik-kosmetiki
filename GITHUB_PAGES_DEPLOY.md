# 🚀 Инструкция по размещению сайта на GitHub Pages

## Шаг 1: Установка Git (если еще не установлен)

1. Скачайте Git с официального сайта: https://git-scm.com/download/win
2. Установите Git с настройками по умолчанию
3. Проверьте установку, открыв PowerShell/CMD и выполнив:
   ```bash
   git --version
   ```

## Шаг 2: Создание GitHub аккаунта

1. Перейдите на https://github.com
2. Нажмите "Sign up" и создайте бесплатный аккаунт
3. Подтвердите email адрес

## Шаг 3: Создание репозитория на GitHub

1. Войдите в свой GitHub аккаунт
2. Нажмите кнопку **"+"** в правом верхнем углу → **"New repository"**
3. Заполните форму:
   - **Repository name**: `butik-kosmetiki` (или любое другое имя)
   - **Description**: "Бутик косметики - сайт магазина"
   - Выберите **Public** (публичный репозиторий)
   - **НЕ** ставьте галочку "Initialize this repository with a README"
4. Нажмите **"Create repository"**

## Шаг 4: Инициализация Git в вашем проекте

Откройте PowerShell или командную строку в папке вашего проекта:

```bash
# Перейдите в папку проекта
cd "C:\Users\kazan\OneDrive\Рабочий стол\agni"

# Инициализируйте Git репозиторий
git init

# Добавьте все файлы
git add .

# Сделайте первый коммит
git commit -m "Initial commit: Бутик косметики"
```

## Шаг 5: Подключение к GitHub репозиторию

После создания репозитория на GitHub, вы увидите инструкции. Выполните:

```bash
# Замените YOUR_USERNAME на ваш GitHub username
git remote add origin https://github.com/YOUR_USERNAME/butik-kosmetiki.git

# Отправьте код на GitHub
git branch -M main
git push -u origin main
```

**Примечание**: GitHub попросит вас ввести логин и пароль. Если используете двухфакторную аутентификацию, создайте Personal Access Token:
- Настройки → Developer settings → Personal access tokens → Tokens (classic)
- Создайте новый token с правами `repo`
- Используйте его вместо пароля

## Шаг 6: Включение GitHub Pages

1. Перейдите в ваш репозиторий на GitHub
2. Откройте вкладку **"Settings"** (вверху справа)
3. В левом меню найдите **"Pages"** (в разделе Code and automation)
4. В разделе **"Source"** выберите:
   - Branch: **main** (или **master**)
   - Folder: **/ (root)**
5. Нажмите **"Save"**

## Шаг 7: Доступ к сайту

Через 1-2 минуты ваш сайт будет доступен по адресу:
```
https://YOUR_USERNAME.github.io/butik-kosmetiki/
```

Где `YOUR_USERNAME` - ваш GitHub username, `butik-kosmetiki` - имя репозитория.

## Шаг 8: Подключение собственного домена (опционально)

Если у вас есть домен (например, butik-kosmetiki.ru):

1. В настройках GitHub Pages (Settings → Pages) введите ваш домен в поле "Custom domain"
2. Настройте DNS записи у вашего регистратора домена:
   - Тип: **A** записи
   - Значения:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - Или **CNAME** запись:
     - Имя: `www` (или `@` для корневого домена)
     - Значение: `YOUR_USERNAME.github.io`

## Обновление сайта

Когда вы внесете изменения в код:

```bash
# Добавьте измененные файлы
git add .

# Сделайте коммит
git commit -m "Описание изменений"

# Отправьте на GitHub
git push
```

Изменения появятся на сайте через 1-2 минуты.

## Полезные команды Git

```bash
# Проверить статус файлов
git status

# Посмотреть историю коммитов
git log

# Отменить изменения в файле
git checkout -- имя_файла
```

## Решение проблем

### Проблема: "fatal: not a git repository"
**Решение**: Убедитесь, что вы выполнили `git init` в правильной папке

### Проблема: "Authentication failed"
**Решение**: 
- Используйте Personal Access Token вместо пароля
- Или настройте SSH ключи

### Проблема: Сайт не обновляется
**Решение**: 
- Подождите 2-3 минуты (GitHub Pages обновляется не мгновенно)
- Очистите кеш браузера (Ctrl+Shift+R)
- Проверьте, что изменения были отправлены: `git push`

### Проблема: Изображения не загружаются
**Решение**: Убедитесь, что все пути к файлам относительные (начинаются с `./` или просто `css/`, `js/`)

## Важные замечания

1. ✅ GitHub Pages поддерживает только статические сайты (HTML, CSS, JS)
2. ✅ Все файлы должны быть в корне репозитория или в папке `docs`
3. ✅ Максимальный размер репозитория: 1 GB
4. ✅ Бесплатный план: до 1 GB трафика в месяц
5. ✅ Сайт доступен только через HTTPS
